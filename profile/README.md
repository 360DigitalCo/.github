## Other Projects:

- Orbit Browser: A privacy browser optimized for 360 built from the ground up using `Rust,` `Gecko` `native webview's` and `webdev utils` and no Chromium.
- Acadia: Initially made as a temporary project for our Robotics Team as a better version of Google Scholar, with more sources to cite, a better trust ranking system            and a cleaner UI creating the balance between the feel of the old web and the advancements of the modern.
- 360ForAndroid: An APK made through a GitHub Actions workflow to build a native and redesigned version of 360 specifically for Android systems!
- 360-CLI: During the summer of 2025, Zaki and Mingze learned bash scripting and to compensate for work they may miss for 460 because of heavy studies on the upcoming year, they made a quick & lightweight CLI that anyone can run and install!
